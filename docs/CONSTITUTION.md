## 1. Domain & Financial Invariants (`CONST-DOM-01`..`CONST-DOM-09`)

| ID | Rule | Enforced Invariants & Authoritative Anchors |
| :--- | :--- | :--- |
| **`CONST-DOM-01`** | **Server-Calculated Visa Duration Tier (`OD-09c`)** | Visa tier (`short_term` <= 30 inclusive KSA calendar days vs `long_term` 31–90 days, where `totalKsaDays = stayNights + 1`) MUST be computed server-side from mandatory KSA Arrival and Departure dates (`calculateVisaTierAndCost` in `lib/domain/visa-calc.ts`, `app/actions/applications.ts`). Never expose a manual visa-tier selector to pilgrims, and strictly require KSA Arrival & Departure dates on `Visa Only` submissions (`OD-09c`). |
| **`CONST-DOM-02`** | **Masar Hotel-Linked SAR Brackets vs Fixed PKR (`OD-09a`)** | When `includeHotels = true` (`withMasar = true`), short-term visas (`<= 30` days) resolve across Nusuk Masar brackets (`<= 10d`, `<= 15d`, `<= 21d`, and `22–30d` via `withMasar28DaysSar` / `withMasar30DaysSar`) converted by live `agency_settings.sarToPkrRate`. Standalone `Visa Only` (`withMasar = false`) strictly uses fixed admin PKR columns (`shortTermPricePkr`, `longTermPricePkr`), never raw SAR FX multiplication. |
| **`CONST-DOM-03`** | **Fixed Rate vs Live Rate vs `"On Request"` Integrity (`OD-09b`)** | Only `Visa Only` mode and active fixed `groupPackages` (`price > 0`) display immediate fixed PKR rates. All volatile custom pillars (`Flights`, `Hotels`, `Transport`, `Ziyarat`) display `"Live Rate — Confirmed upon submission"`. In Studio Mode B (`net_plus_markup`), unpriced `0` / blank supplier room tiers MUST remain `0` (`"On Request"` / `"N/A"`) — never adding `commissionPkr` onto `0` (`calculatePackageDisplayPrices` in `lib/domain/marketing-ops.ts`), and flyers with `> 10` cards paginate cleanly across sheets (`Sheet 1/N`) without dropping packages. |
| **`CONST-DOM-04`** | **Makkah No-Airport & Route Sequence Locks** | Makkah has no civilian airport. Any itinerary starting in Makkah (`makkah_madinah`, `makkah_madinah_makkah`, `makkah_madinah_jeddah`, `makkah_only`) locks Entry Airport to Jeddah (`JED`) with immediate ground transfer to Makkah (`OD-09c` permits `includeTransport = false` self-arranged JED→Makkah transfer only with explicit pilgrim acknowledgment while keeping `JED` locked). `makkah_madinah_jeddah` chains `JED_MAK` → `MAK_MED` → `MED_JED` directly from Madinah Hotel to Jeddah Airport without a second Makkah hotel stay (`lib/domain/date-chaining.ts`). Single-city stays (`makkah_only`, `madinah_only`) remain valid with Visa enabled (`OD-09a`). |
| **`CONST-DOM-05`** | **Beds/Seats (`Adults + Children`) vs Infant Passports (`OD-09d`)** | Hotel room beds and road vehicle seat capacities (`getBillableSeatCount` in `lib/domain/vehicle-capacity.ts`) count `Adults + Children` only. `Infants (<2 yrs)` consume `0` hotel beds and `0` vehicle seats, MUST be counted in `totalPassportCount = Adults + Children + Infants` for visa costing, and MUST include infant airfare (`infantPricePkr > 0`) whenever `includeFlights = true` and `infants > 0` (`OD-09d`). |
| **`CONST-DOM-06`** | **Room Splitter & Fleet Capacity Discipline (`T-048`, `OD-09c`)** | `calculatePrivateRoomSplits` (`lib/domain/room-splitter.ts`) strictly honors each hotel's `allowedRoomTypes` (`double = 2`, `triple = 3`, `quad = 4`) and never emits disallowed room types. `calculateVehicleQuantity` (`lib/domain/vehicle-capacity.ts`) evaluates both `seatCapacity` and `luggageCapacity`, returns only canonical `vehicleCategoryEnum` road classes (`sedan \| suv \| van \| minibus \| bus`, excluding `train` from road upgrades), and emits luggage warnings when bags exceed single-vehicle luggage capacity. |
| **`CONST-DOM-07`** | **Atomic Group Seat Deduction on `approved` (`T-022`, `OD-09d`)** | Public group submissions validate available seats (`totalSeats - bookedSeats >= Adults + Children`) and bind `departureId` strictly to its owning `packageId`, but `group_departures.booked_seats` (`Adults + Children`, `0` infant seats) deducts atomically via `SELECT ... FOR UPDATE` inside `withTransaction()` (`db/index.ts`, `app/actions/quotes.ts`) ONLY when an admin transitions an application to `status = 'approved'` (and releases seats atomically on `approved → rejected \| cancelled`). |
| **`CONST-DOM-08`** | **Append-Only Payment Ledger & Voucher Unlock Gate (`OD-03`, `OD-04`)** | All pilgrim payments append exclusively to the immutable `application_payments` ledger (`amount_pkr > 0` SQL `CHECK`, `ON DELETE RESTRICT`) with private R2 bank-receipt proof uploads (`OD-03`). Admin vouchers and capability-signed public QR `/voucher/[token]` routes (`evaluateAdminVoucherGate` in `components/admin/applications/voucher-gate.ts`) unlock strictly when `status === 'approved'` AND `paymentStatus IN ('deposit_paid', 'paid_in_full')` with positive verified payments (returning HTTP `403` `forbidden()` otherwise), badging `DEPOSIT VERIFIED — BALANCE DUE` vs `PAID IN FULL`. |
| **`CONST-DOM-09`** | **Indicative Hajj 2027 Pre-Registration (`OD-09e`)** | Hajj 2027 tiers managed in `/admin/catalog` (`hajj_packages`) and displayed on `/hajj-2027` are strictly non-binding indicative pre-registration estimates subject to Saudi Ministry of Hajj & Umrah (Nusuk) and Pakistan MoRA quota announcements (`HAJJ_2027_REGULATORY_DISCLAIMER` in `components/seo/guides-hajj-data.ts`). Zero online deposits or binding e-commerce checkout states may be collected or marked `InStock`. |

## 2. Security, Privacy & Isolation Invariants (`CONST-SEC-01`..`CONST-SEC-08`)

| ID | Rule | Enforced Invariants & Authoritative Anchors |
| :--- | :--- | :--- |
| **`CONST-SEC-01`** | **Disabled Public Admin Sign-Up (`403`)** | Better Auth (`lib/auth.ts`) enforces `disableSignUp: true`; public `POST /api/auth/sign-up/*` requests return `403`. Staff accounts are provisioned exclusively by `super_admin` with forced first-login password rotation (`mustChangePassword = true`) and transactional email or temporary password reset (`OD-02`). |
| **`CONST-SEC-02`** | **Live DB `isActive` Revocation & Strict Dual RBAC (`T-004`, `OD-07`)** | `lib/auth-guard.ts` queries the live PostgreSQL `user` record on every server request and deletes `session` rows immediately when `isActive = false` or user is missing. Every admin Server Action and route enforces `requireAdmin()` (`staff \| super_admin`) or `requireSuperAdmin()` (strictly gating `/admin/settings`, WABA/Social OAuth, master catalog rates, staff CRUD, bulk Meta broadcasts, and CSV exports). |
| **`CONST-SEC-03`** | **100% Entrypoint Zod Validation, Type Safety & Immutable Audit Trail** | Every Server Action, Route Handler, and form payload validates input via `zod` schemas. Code MUST contain `0` `any`, `@ts-ignore`, `@ts-expect-error`, `eslint-disable`, or unvalidated `FormData`. All financial, status, RBAC, and vault mutations record to `audit_logs`, enforced append-only in PostgreSQL by trigger `trg_audit_logs_immutable` (`db/schema/audit-logs.ts`). |
| **`CONST-SEC-04`** | **Staff Wholesale Cost & OAuth Token Redaction (`T-061`)** | Non-`super_admin` (`staff`) sessions MUST NEVER receive supplier net cost (`netSharingPkr`), agency commission (`commissionPkr`), or encrypted OAuth candidate tokens in RSC props, JSON payloads, or `Cmd+K` results (`searchPostPackagesCommandAction` in `app/actions/command-lookup.ts`). |
| **`CONST-SEC-05`** | **Versioned HKDF-AES-256-GCM Vault (`v2:`), Fail-Closed Env & PII-Redacted Logs** | Integration secrets encrypt via `v2:<kid>:<ivHex>:<tagHex>:<ctHex>` HKDF-SHA256 AES-256-GCM (`lib/security/vault.ts` with `ENCRYPTION_KEY` 64-hex chars and `ENCRYPTION_KEY_PREVIOUS` zero-downtime rotation); legacy unauthenticated AES-CBC ciphertexts are hard-rejected. `parseEnv()` (`lib/env.ts`) fails closed in `NODE_ENV=production` on missing secrets, `localhost` URLs, or `SKIP_ENV_VALIDATION`. `lib/logger.ts` redacts phones, emails, JIDs, OTPs, tokens, and Drizzle `.params`. |
| **`CONST-SEC-06`** | **Public vs Private R2 Media Isolation & Automated Retention (`OD-06`)** | Public CDN (`R2_PUBLIC_URL`) serves only non-PII prefixes (`posters/`, `cms/`, `hotels/`). Sensitive prefixes (`passports/`, `whatsapp-media/`, `quotes/`, `quotations/`, `receipts/`) in `PRIVATE_MEDIA_PREFIXES` (`lib/storage/r2.ts`) are served strictly through authenticated/HMAC-signed `10m` `/api/media/[...key]` responses (`Cache-Control: private, no-store`), never `public/uploads/r2-local` or `~/.wrangler` in production. Nightly PKT cron (`trigger/schedules.task.ts`) purges passport scans **60d post-return**, anonymizes unbooked lead PII at **24m**, and retains financial tax ledgers **6y** (Pakistan Income Tax Ordinance 2001 §174). |
| **`CONST-SEC-07`** | **PII-Scrubbed ZDR AI, Deterministic Copilot Math & Hardened Gotenberg (`OD-06`)** | All AI prompts scrub pilgrim PII before transmission; OpenRouter requests enforce `OPENROUTER_ZDR_PROVIDER_OPTIONS` (`data_collection: "deny"` in `lib/ai/models.ts`). AI Quoting Copilot (`lib/ai/quoting-copilot.ts`) restricts LLM output to narrative guidance and computes `100%` of PKR/SAR totals deterministically on the server. Gotenberg v8 (`lib/posters/gotenberg.ts`) escapes all HTML (`escapeHtml`), stays `< 65 KB` via compressed assets, runs `--chromium-disable-javascript=true`, and rejects SSRF targets (`lib/security/ssrf-guard.ts`). |
| **`CONST-SEC-08`** | **Hermetic `.env.audit` (`54329`) Test Isolation & Status Tracker Hardening (`OD-05`)** | `npm test` and `npm run test:e2e` MUST execute strictly against `.env.audit` (`127.0.0.1:54329/alramlah_audit`), enforced by `assertAuditSafeEnvironment()` (`tests/helpers/audit-guard.ts`) — refusing any `neon.tech` URL. Public status lookups (`lookupApplicationStatus` in `app/actions/applications.ts`) require 48-bit CSPRNG `ART-...` references, constant-time `>= 9`-digit E.164 phone matching (`normalizePublicPhone` rejecting `"-------"`), PostgreSQL rate limits (`5/15m` IP, `12/15m` ref), and PII-redacted public DTOs. |

| **`CONST-UI-02`** | **WCAG 2.2 AA Contrast & Gold Text Token Split** | Core surfaces lock to Deep Haramain Emerald (`#0A3622` / `oklch(0.26 0.08 155)`), Warm Ivory (`#FAF7F0` / `oklch(0.975 0.012 85)`), and Crisp Alabaster (`#FFFFFF`). | **`CONST-UI-03`** | **Accessible Sacred Arabic & RTL Typography (`OD-08`)** | Every Arabic phrase or sacred script (`سفريات الرملة`, Quranic/Haramain expressions) MUST render via `<ArabicText lang="ar" dir="rtl">` (`components/public/arabic-text.tsx`) with `unicodeBidi: "isolate"`. | **`CONST-UI-05`** | **Tabular Numerals, LCP Image Discipline & Zero Axe Violations** | All PKR/SAR prices, meter distances, dates, and `ART-...` codes use `tabular-nums` (`font-mono` for codes/figures).
