## 1. Classification Rubric (`SWARM_PROMPT.md` §0 & §5.3)

Every capability claimed in `docs/PLATFORM_MASTER_BRIEF.md` is classified into **one** of six strict statuses:

- **`VERIFIED-WORKING`**: Pure deterministic in-memory domain math, URL/phone normalizers, static server-rendered legal routes, or clean server-side `redirect()` stubs whose exact target tab/event exists in code with **zero** unexercised DB/external API runtime dependencies and **zero** defects. *(Per `SWARM_PROMPT.md` §0, unit tests over mocks do **not** elevate an unexercised integration to `VERIFIED-WORKING`.)*
- **`IMPLEMENTED-UNVERIFIED`**: Full vertical slice (UI + Server Action / Route Handler + Zod validation + auth guard + Drizzle persistence / external adapter) is cleanly implemented in source code, but requires live Neon / Cloudflare R2 / Gotenberg / Meta / Google / TikTok / Trigger.dev sandbox or production credentials to prove end-to-end runtime behavior.
- **`PARTIAL`**: Core code exists, but the slice is half-wired, silently degrades, skips validation/rate-limiting, diverges from the brief's stated architecture (e.g., hardcoded inline execution instead of Trigger.dev, missing `groupPackages` in `Cmd+K`, missing passport inputs, unbounded full-table memory loads), or violates Meta 24-hour window rules.
- **`STUB/FAKE`**: Feature presents deterministic mock numbers or static `if`-thresholds where live AI curation or live platform telemetry is claimed (e.g., `SmartInsightsBanner` static thresholds, `buildDeterministicMockAnalytics` fabricating social metrics on error and for all Composio accounts).
- **`MISSING`**: Claimed capability, route, Server Action, scheduled cron, or dependency does not exist in the codebase (e.g., `react-email` transactional quotation email, self-service pilgrim online quote approval, admin password reset, `daily-scheduled-distribution-runner` cron).
- **`BROKEN`**: Confirmed code, security, link, data-integrity, or production-topology defect that fails or misbehaves at runtime (e.g., `wa.me/03274029701` links missing `92` country code, legacy redirects landing on the wrong hub tab, unauthenticated `"use server"` action `executeScheduledPostNowAction`, `neon-http` driver incapable of `db.transaction()`, in-memory Baileys `socketMap` unreachable from Trigger.dev workers and ephemeral on Vercel, `EROFS` local upload fallback on Vercel, unescaped HTML injection in Gotenberg renderers, IG single-video Reel/Story publish without container polling, Meta token refresh clobbering Page tokens with User tokens, `sla-overdue-quote-monitor` mutating customer `specialRequests`, admin-gated `/voucher` blocking pilgrims).
