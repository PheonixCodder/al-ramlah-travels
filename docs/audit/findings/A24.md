## 2. Complete 21-File Audit & Classification Ledger (`web/tests/`)

Every pre-audit file in `web/tests/` (`20` `.test.ts` files + `tests/test-env.ts`) was audited line-by-line and classified across six empirical test archetypes:
- **Pure Unit (`PU`)**: Exercises real pure TypeScript functions in `lib/**` without network/DB mocks.
- **Schema/Metadata Smoke (`SM`)**: Only calls `zodSchema.parse()` or checks `typeof fn === "function"` / `task.id === "..."` / `"col" in table`.
- **Copy-Paste Self-Test (`CP`)**: Re-declares a copy-pasted function or inline boolean expression inside the `.test.ts` file itself (`0` app code exercised).
- **Source-File Regex/FS Grep (`SG`)**: `0` files perform `fs.readFileSync` source-code regex grepping (`multimodal-and-gotenberg.test.ts:3` is the sole `node:fs/promises` importer, used to inspect/delete files written into `public/uploads/r2-local/`).
