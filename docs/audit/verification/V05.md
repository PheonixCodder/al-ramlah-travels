## 8. Residual Non-Blocking Adversarial Observations (`P3` Informational)

None of the items below reopen any `P0`/`P1`/`P2` finding or block Go-Live; they are recorded for post-launch hygiene:

1. **`OBS-V05-01` (`P3` — Non-Prod Dead Branch in `trigger/process-inbound-whatsapp.task.ts:240-247`)**:
   - `process-inbound-whatsapp.task.ts:240-247` retains `if (process.env.NODE_ENV !== "production" && account.encryptedAccessToken === "mock_offline_token")` solely before the best-effort `markWhatsAppMessageAsRead` receipt call (`L250`). It is strictly unreachable when `NODE_ENV === "production"`, and `runWhatsappAutoResponder` (`lib/whatsapp/auto-responder.ts:758-774`) always calls `decrypt()` directly and fails closed (`NEEDS_REAUTH`). Can be deleted once legacy local fixtures stop seeding `"mock_offline_token"`.
2. **`OBS-V05-02` (`P3` — Cosmetic Sample Recipient Phone Literal in `whatsapp-broadcast-drawer.tsx:557` & Unused CI Env Var)**:
   - `components/admin/campaigns/whatsapp-broadcast-drawer.tsx:557` uses `phone: parsedRecipients[0]?.phone || "+923008451122"` as a synthetic *recipient* variable preview (`"Muhammad Ali"`) before CSV upload if a template body uses `{{phone}}`. Never rendered as agency contact info or sent outbound, though changing the placeholder digits to `+923000000000` avoids grep overlap with retired `OD-10` helpline digits. Similarly, `.github/workflows/ci.yml:51` and `tests/setup/run-all-tests.mjs:39` still pass `WHATSAPP_MOCK_MODE: "true"` in test env even though `WHATSAPP_MOCK_MODE` is no longer read anywhere in `lib/whatsapp/` runtime (only checked as an operator warning flag in `components/admin/settings/config-health.ts:238`).
3. **`OBS-V05-03` (`P3` — Process-Local YouTube Daily Quota Counter in `lib/social/providers/youtube.ts:46-87`)**:
   - `youtubeDailyQuotaLedger` tracks the `10,000`-unit daily YouTube Data API v3 budget in an in-memory `Map<string, number>`, which resets across Trigger.dev container cold starts; upstream `HTTP 403 quotaExceeded` is still caught and surfaced cleanly (`youtube.ts:437-440`). Persisting daily units in PostgreSQL is an optional post-GA enhancement.
4. **`OBS-V05-04` (`P3` — `trigger/extract-packages.task.ts:253` Direct `fetch` on Stored Flyer URL)**:
   - When generating normalized `1080×1520` social JPEGs for extracted supplier flyers, `extract-packages.task.ts:253` calls `fetch(resolvedMediaUrl)` without wrapping in `assertSafeSocialMediaUrl` (mitigated because `supplier_flyers.fileUrl` is written only by `requireAdmin` Studio upload actions pointing at configured R2 buckets, unlike `lib/social/normalize-media.ts` which wraps every fetch in `fetchSafeSocialMediaBuffer`).
