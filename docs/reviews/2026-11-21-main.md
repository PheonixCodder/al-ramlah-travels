## Minor

### 🟡 `standardFallbackPositive` uses option-switched `sharingTierRate` instead of standard package rate, `components/public/group-booking-modal.tsx:396`
**Problem**: `standardFallbackPositive` (`components/public/group-booking-modal.tsx:395-400`) mixes `sharingTierRate` (which switches to `matchedHotelOption.sharingPricePkr` at lines `256-257` when a `multiHotelOptions` radio is selected) with the standard package's `quad`, `triple`, and `double` tariffs.
**Why it matters**: For a package whose standard `quadPricePkr` is `<= 0` (`"On Request"`), selecting a `multiHotelOptions` radio alters the `"Standard Featured Package Hotels"` radio label (`From PKR ...` at line `630`) to include the selected hotel option's sharing price instead of the standard package's own sharing rate.
**Suggested fix**: Compute `standardSharingRate` from `activeBatch?.sharingPriceOverridePkr ?? pkg.sharingPricePkr ?? pkg.quadPricePkr` (consistent with lines `394-399`) and pass that into `standardFallbackPositive`.

### 🟡 `GroupPackagesSection` and `ZiyaratShowcaseClient` omit `shouldBypassNextImageOptimization`, `components/public/group-packages-section.tsx:532-538`
**Problem**: `app/(public)/umrah-packages/page.tsx:294` and `app/(public)/umrah-packages/[slug]/page.tsx:242` guard dynamic banner `<Image>` tags with `unoptimized={shouldBypassNextImageOptimization(pkg.bannerUrl)}`, whereas `components/public/group-packages-section.tsx:532-538` (`pkg.bannerUrl`) and `components/public/marketing-client-islands.tsx:385-391` (`site.imageUrl`) omit it.
**Why it matters**: If an admin saves a supplier banner or Ziyarat image URL whose hostname is outside `next.config.ts` `images.remotePatterns`, the `/umrah-packages` hub and `[slug]` spoke render safely, while `/` (`HomePage`) throws a Next.js `Invalid src prop` runtime error.
**Suggested fix**: Apply `unoptimized={shouldBypassNextImageOptimization(...)}` to dynamic DB image `<Image>` elements in `GroupPackagesSection` and `ZiyaratShowcaseClient`.
