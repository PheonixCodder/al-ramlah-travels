## 1. Summary & Context

Between Slices 1 and 42 (`Specs 0001–0023`), **Al Ramlah Travels** (`سفريات الرملة`) rapidly assembled a broad vertical travel commerce surface spanning a 6-step Custom Umrah Journey Builder, Seasonal Group Packages, Hajj 2027 Inquiries, a B2B Multimodal Flyer-Wrapping & 4K Gotenberg Poster Studio, a Core 5 Social Media Scheduler (`Instagram`, `Facebook`, `TikTok`, `YouTube`, `Google Business Profile`), a Dual-Engine WhatsApp CRM (`Meta Cloud API v21.0` + `@whiskeysockets/baileys` Linked Devices), a Durable AI Quoting Copilot (`Trigger.dev Cloud v4`), and an Applications Kanban & Quotation PDF Desk.

Despite passing `tsc --noEmit`, `next build`, and `429` unit tests, the platform owner observed that **the application was not genuinely production-ready**. Wave 0 (`a00-truth`, `w0-env`) and Wave 1 (`A01`–`A26`) conducted an exhaustive, zero-trust forensic audit against a disposable PostgreSQL 16 container (`alramlah-audit-pg` on `127.0.0.1:54329`) and every source file in `web/`, treating `docs/PLATFORM_MASTER_BRIEF.md` strictly as unverified claims.

This specification (`Spec 0024`) records the empirical Wave 0–1 ground truth, locks in the architectural remediations and §11 Owner Decision gates (`OD-01`..`OD-11`), defines the conflict-free **12-Fixer Wave 3 Build Plan (`W3A → W3B → W3C`)**, and codifies the **Gate A Production Readiness Acceptance Criteria (§9.4)** and **22 End-to-End Verification Journeys (`J1`–`J22`)** that must pass 100% before **Phase B (`Spec 0025 — SEO Readiness`)** is permitted to begin.

## 3. Core Architecture Decisions & §11 Owner Decision Gates

### 3.1 Non-Negotiable Technical Architecture Decisions

1. **Dual-Driver Drizzle Client (`db/index.ts`)**:
   - Keep `neon-http` for low-latency single-statement RSC reads where appropriate, **plus** expose a transactional `Pool` client (`drizzle-orm/neon-serverless` over WebSocket in Neon prod; `drizzle-orm/node-postgres` `pg.Pool` when `DATABASE_URL` uses local TCP `127.0.0.1` / CI Postgres) via `withTransaction(fn)` so multi-table mutations (`applications`, `quotes`, `bookedSeats`, `supplier_flyer_packages`, `audit_logs`) are strictly ACID-atomic, and `drizzle-kit migrate` + `db/seed.ts` run cleanly against disposable local Postgres without `dotenv` `.env` leakage.
2. **Fail-Closed Production Environment & Runtime Boundaries (`lib/env.ts`, `dispatch.ts`, `r2.ts`, `gotenberg.ts`)**:
   - Eliminate `SKIP_ENV_VALIDATION=1` secret placeholders at runtime (`only` permit schema-build phase checks where no runtime server starts). Require HTTPS `NEXT_PUBLIC_APP_URL` & `BETTER_AUTH_URL`, 64-hex `ENCRYPTION_KEY` (with optional `ENCRYPTION_KEY_PREVIOUS` dual-key rotation), R2 credentials, `TRIGGER_SECRET_KEY`, `GOTENBERG_API_URL` + `GOTENBERG_API_KEY`, and `META_APP_SECRET` in `NODE_ENV=production`.
   - Hard-block `public/uploads/r2-local/` writes, `/api/uploads/local`, `~/.wrangler` token scraping, `chromium-cdp.ts` local Chrome spawning, `inlineRunner` Trigger fallback, `WHATSAPP_MOCK_MODE` / `mock_*` / `sim_*` token backdoors, fake `wamid.sim_*`/`wamid.bridge_*` catch rows, and `buildDeterministicMockAnalytics` in production.
3. **Public vs Private R2 Storage Partition (`lib/storage/r2.ts`, `app/api/media/[...key]/route.ts`)**:
   - Public marketing assets (`posters/`, `cms/`, `hotels/`) may use public CDN URLs with unguessable UUIDv4/HMAC suffixes.
   - Sensitive pilgrim & commercial artifacts (mirrored WhatsApp media/passports, 3-page Quotation PDFs, raw wholesale supplier flyers) MUST be stored under private prefixes/bucket ACLs and served exclusively via short-lived presigned GET URLs or authenticated `/api/media/...` proxy routes (admin session OR cryptographically signed pilgrim quote/voucher token).
4. **Zero-Paid-Infra Shared Security Primitives (`F-PLAT`)**:
   - **Rate Limiting (`lib/rate-limit.ts`)**: Better Auth `rateLimit: { storage: "database" }` + atomic PostgreSQL `INSERT INTO rate_limit_buckets ... ON CONFLICT DO UPDATE` enforcing strict per-IP / per-key budgets across login, `lookupApplicationStatus`, all 4 public lead forms, and `/api/uploads/presign`.
   - **Immutable Audit Trail (`db/schema/audit-logs.ts`, `lib/audit-log.ts`)**: Append-only `audit_logs` table protected by a PostgreSQL `BEFORE UPDATE OR DELETE` exception trigger, recording redacted `before_state` / `after_state`, actor, IP, and `requestId` across auth, staff RBAC, quote versions, status/payment changes, credentials, DNC, and catalog rates.
   - **Zero-PII Structured Logger (`lib/logger.ts`)**: Recursive key/regex redaction masking phones (`+92***01`), tokens, WhatsApp pairing codes, and stripping `DrizzleQueryError.params`, paired with `x-request-id` correlation propagation across Next.js → Trigger.dev → Gotenberg.
   - **HTML & Outbound Fetch Guards (`lib/security/*`)**: Mandatory `escapeHtml()` across every Gotenberg template (`--chromium-disable-javascript=true` + `--chromium-host-resolver-rules` blocking RFC1918/link-local `169.254.169.254`), plus `safeFetchJson()` enforcing `AbortSignal.timeout()`, `Content-Type` verification before `.json()`, `Retry-After` parsing, and SSRF host allowlisting.
5. **Single Luxury Haramain Light Theme & WCAG 2.2 AA Lock (`app/globals.css`, `F-UX`)**:
   - Lock Tailwind v4 `@custom-variant dark (&:where(.dark, .dark *));` and `color-scheme: light` so OS Dark Mode never activates partial `dark:*` utilities; introduce darkened accessible gold text token (`--gold-text` / `#8A6914` ≥ `4.6:1` on `#FAF7F0` & `#FFFFFF`) while keeping `#C5A059` strictly for large decorative borders/fills on deep emerald `#0A3622`; enforce `tabular-nums` on all prices/dates/codes.
